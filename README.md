# YouTube / Twitch GIF Recorder

YouTube와 Twitch에서 재생 중인 영상을 간편하게 **녹화, 스크린샷, GIF/WebP 움짤**로 저장할 수 있도록 플레이어에 기능을 추가하는 Tampermonkey UserScript입니다.

플레이어 컨트롤바에 녹화·스크린샷·움짤 버튼을 추가하며, 키보드 단축키를 이용해 더욱 빠르게 사용할 수 있습니다.

## ✨ 주요 기능

* 🎥 **YouTube / Twitch 영상 녹화**
* 📸 **영상 스크린샷 저장**
* 🎞️ **GIF 움짤 제작**
* 🖼️ **WebP 애니메이션 제작**
* ✂️ **움짤 시작 / 종료 구간 지정**
* 🎚️ **FPS / 해상도 / 화질 설정**
* 🖼️ **GIF 일반 / 고화질 모드 선택**
* ⚡ **고화질 GIF 제작을 위한 gifski 지원**
* 🗜️ **WebP 손실 / 무손실 압축 선택**
* 🤖 **움짤 자동 생성 기능**
* 📶 **일반 영상 녹화 비트레이트 설정**
* 💾 **설정값 자동 저장**
* ⌨️ **녹화 / 스크린샷 / 움짤 단축키 커스터마이징**
* 🔄 **YouTube 페이지 이동(SPA)에도 버튼 자동 대응**
* 📁 **영상/방송 제목을 기반으로 한 자동 파일명 생성**

## 🌐 지원 사이트

현재 다음 사이트를 지원합니다.

* **YouTube**
* **Twitch**

각 사이트의 플레이어 컨트롤 영역에 녹화, 스크린샷, 움짤 버튼이 자동으로 추가됩니다.

## 📥 설치

### 1. Tampermonkey 설치

먼저 브라우저에 **Tampermonkey**를 설치합니다.

### 2. UserScript 설치

GitHub의 `youtube-gif-recorder.user.js` 파일에서 **Raw** 버튼을 클릭하면 Tampermonkey 설치 화면이 나타납니다.

설치 후 YouTube 또는 Twitch에 접속하면 플레이어에 기능 버튼이 추가됩니다.

스크립트에는 업데이트 및 다운로드 URL도 등록되어 있어 GitHub의 최신 버전을 기준으로 업데이트할 수 있습니다.

## 🎮 사용 방법

플레이어 컨트롤바에 다음 버튼이 추가됩니다.

**● 녹화**

현재 재생 중인 영상을 녹화합니다.

버튼을 다시 누르면 녹화를 종료하고 파일을 저장합니다.

브라우저에서 지원하는 형식에 따라 **MP4 또는 WebM**으로 저장됩니다.

**📷 스크린샷**

현재 영상의 원본 영상 크기로 프레임을 캡처하여 PNG 이미지로 저장합니다.

**GIF**

현재 영상을 움짤 녹화한 뒤 별도의 움짤 편집창에서 원하는 구간과 옵션을 설정하여 GIF 또는 WebP로 저장할 수 있습니다.

## ⌨️ 기본 단축키

| 기능        | 기본 단축키 |
| --------- | ------ |
| 🎥 녹화     | `F9`   |
| 📸 스크린샷   | `F10`  |
| 🎞️ 움짤 녹화 | `F8`   |

단축키는 설정 메뉴에서 원하는 키로 변경할 수 있습니다.

단축키 설정 시 서로 같은 키를 사용할 수 없도록 중복 검사도 적용되어 있습니다.

또한 입력창이나 텍스트 편집 영역에 커서가 있을 때는 단축키가 작동하지 않도록 되어 있어 일반적인 입력을 방해하지 않습니다.

## ⚙️ 움짤 설정

움짤 제작 시 다음 항목을 설정할 수 있습니다.

### FPS

움짤의 프레임 수를 설정합니다.

기본 제공 프리셋:

`10 / 15 / 20 / 25 / 30 / 40 / 60 FPS`

원하는 값을 직접 입력하는 것도 가능합니다.

### 가로 크기

움짤의 가로 해상도를 설정합니다.

기본 제공 프리셋:

`640 / 720 / 960 / 1280 / 1440 / 1600 / 1920 px`

또는 **원본 크기**를 사용하거나 직접 입력할 수 있습니다.

### 화질

화질 값은 `1~20` 범위에서 설정할 수 있습니다.

일반적인 GIF/WebP 압축에서는 **낮은 값일수록 높은 화질**, 높은 값일수록 낮은 화질로 동작합니다.

단, 일부 고화질/무손실 모드에서는 이 설정이 적용되지 않습니다.

### 저장 형식

* GIF
* WebP

중에서 선택할 수 있습니다.

## 🖼️ GIF 고화질 모드

GIF는 두 가지 방식으로 제작할 수 있습니다.

### 일반

`gif.js`를 사용하여 GIF를 생성합니다.

### 고화질

**gifski-wasm**을 사용하여 고품질 GIF를 생성합니다.

## 고화질 모드는 일반 GIF보다 인코딩 시간이 오래 걸릴 수 있습니다. 코드에서는 gifski를 이용해 프레임을 처리하고 높은 품질 설정으로 GIF를 생성하도록 되어 있습니다.

## 🖼️ WebP

WebP 애니메이션 제작을 지원합니다.

### 손실 압축

화질 값을 조절하여 파일 크기와 화질을 조정할 수 있습니다.

### 무손실 압축

화질 손실 없이 WebP를 생성합니다.

무손실 모드에서는 일반적인 화질 설정이 적용되지 않습니다.

---

## ✂️ 움짤 구간 지정

움짤 편집창에서 시작과 종료 시간을 직접 지정할 수 있습니다.

예:

`시작 10.5초 → 종료 15.0초`

또한 현재 영상 재생 위치를 기준으로 시작/종료 시간을 바로 지정할 수 있으며, **전체 구간**으로 초기화할 수도 있습니다.

따라서 긴 영상을 먼저 움짤 녹화한 뒤 원하는 부분만 잘라서 GIF/WebP로 제작할 수 있습니다.

---

## 🤖 자동 생성

**자동 생성** 옵션을 활성화하면 별도의 편집 과정을 거치지 않고 저장된 설정값을 사용하여 움짤을 바로 생성합니다.

즉,

`움짤 녹화 → 변환 → 자동 다운로드`

과정으로 사용할 수 있습니다.

자동 생성이 꺼져 있으면 움짤 녹화가 끝난 후 편집창에서 구간, FPS, 해상도, 화질 및 저장 형식을 직접 변경할 수 있습니다.

---

## 🎥 영상 녹화 설정

일반 영상 녹화에는 **비트레이트 설정**을 사용할 수 있습니다.

기본 제공 옵션:

`1 / 2 / 3 / 4 / 8 / 12 / 20 Mbps`

또는 직접 Mbps 값을 입력할 수 있으며, **자동(해상도별)** 설정도 지원합니다.

자동 모드에서는 영상 해상도에 따라 비트레이트가 결정됩니다.

* 2160p 이상 → 40 Mbps
* 1440p 이상 → 20 Mbps
* 1080p 이상 → 12 Mbps
* 720p 이상 → 8 Mbps
* 그 이하 → 4 Mbps

> ※ 움짤 제작 과정에서는 별도의 녹화 비트레이트 설정이 적용되지 않습니다.

---

## 📁 자동 파일명

저장되는 파일은 영상/방송 제목을 기반으로 자동으로 이름이 지정됩니다.

예:

`영상 제목_녹화_2026-08-31_14-05-23-123.mp4`

`영상 제목_스크린샷_2026-08-31_14-06-10-456.png`

`방송 제목_움짤_2026-08-31_14-07-32-789.gif`

파일명에 현재 날짜와 시간뿐 아니라 밀리초까지 포함되기 때문에 같은 영상에서 여러 번 저장하더라도 파일명이 겹칠 가능성을 크게 줄였습니다.

YouTube는 플레이어 제목을 우선 사용하고, Twitch는 방송 제목을 가져오도록 되어 있습니다. 제목을 가져오지 못하는 경우 페이지 제목을 대신 사용합니다.

Windows에서 파일명으로 사용할 수 없는 문자와 예약된 파일명도 자동으로 처리합니다.

또한 녹화/움짤 시작 시점의 제목을 기억하기 때문에 녹화 도중 제목이 변경되더라도 해당 녹화물의 파일명은 시작 당시 제목을 사용합니다.

## 🧠 WebP 메모리 경고

WebP는 변환 과정에서 여러 프레임을 메모리에 보관하기 때문에

* 높은 FPS
* 높은 해상도
* 긴 영상 구간

을 동시에 사용할 경우 메모리 사용량이 크게 증가할 수 있습니다.

스크립트는 현재 설정을 기준으로 예상 메모리 사용량을 계산하여 높은 경우 경고를 표시합니다.

특히 매우 높은 메모리 사용량이 예상되는 경우에는 변환 전에 계속 진행할지 확인합니다.
변환에 실패한다면 다음 항목을 낮춰 다시 시도하는 것을 권장합니다.

* FPS
* 가로 크기
* 움짤 구간

저장되는 주요 설정:

* FPS
* 가로 크기
* 화질
* GIF / WebP
* WebP 손실 / 무손실
* GIF 일반 / 고화질
* 자동 생성
* 녹화 비트레이트
* 녹화 단축키
* 스크린샷 단축키
* 움짤 단축키

Tampermonkey 메뉴에서

## ⚠️ 주의사항

### 메모리 사용량

GIF/WebP 변환은 영상의 길이, FPS, 해상도에 따라 상당한 메모리를 사용할 수 있습니다.

특히 고해상도 + 높은 FPS + 긴 구간의 WebP 변환은 메모리 부족으로 실패할 수 있습니다.

### 변환 시간

고화질 GIF(gifski) 모드는 일반 GIF보다 인코딩에 더 많은 시간이 걸릴 수 있습니다.

### 브라우저 호환성

영상 녹화에는 브라우저의 `MediaRecorder` 및 `video.captureStream()` 기능을 사용합니다.

브라우저에 따라 지원되는 녹화 형식(MP4/WebM)이 달라질 수 있습니다.

### 사이트 변경

YouTube와 Twitch의 플레이어 구조가 변경될 경우 버튼이 정상적으로 표시되지 않거나 일부 기능이 작동하지 않을 수 있습니다.

스크립트는 YouTube의 SPA 페이지 이동에 대응하기 위해 플레이어 DOM 변화를 감시하여 버튼을 다시 생성하도록 되어 있습니다.

### 외부 라이브러리

GIF/WebP 변환을 위해 외부 CDN에서 라이브러리를 불러옵니다.

* `gif.js`
* `gifski-wasm`
* `wasm-webp`

따라서 해당 CDN에 접근할 수 없는 환경에서는 움짤 변환 기능이 정상적으로 작동하지 않을 수 있습니다.
