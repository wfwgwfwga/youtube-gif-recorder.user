# YouTube / Twitch / CHZZK GIF Recorder

YouTube, Twitch, CHZZK에서 재생 중인 영상을 간편하게 **녹화, 스크린샷, GIF/WebP 움짤**로 저장할 수 있도록 플레이어에 기능을 추가하는 Tampermonkey UserScript입니다.

각 플랫폼의 플레이어에 녹화·스크린샷·움짤 버튼을 추가하며, 키보드 단축키를 이용해 더욱 빠르게 사용할 수 있습니다.

## ✨ 주요 기능

* 🎥 **YouTube / Twitch / CHZZK 영상 녹화**
* 📸 **영상 스크린샷 저장**
* 🎞️ **GIF 움짤 제작**
* 🖼️ **WebP 애니메이션 제작**
* ✂️ **움짤 시작 / 종료 구간 지정**
* 🎚️ **FPS / 해상도 / 화질 설정**
* 🖼️ **GIF 일반 / 고화질 모드 선택**
* ⚡ **gifski를 이용한 고화질 GIF 제작**
* 🗜️ **WebP 손실 / 무손실 압축 선택**
* 🤖 **움짤 자동 생성**
* 📶 **영상 녹화 비트레이트 설정**
* 💾 **설정값 자동 저장**
* ⌨️ **단축키 커스터마이징**
* 📁 **영상/방송 제목 기반 자동 파일명 생성**
* 🔄 **YouTube SPA 페이지 이동 자동 대응**

## 🌐 지원 플랫폼

현재 다음 플랫폼을 지원합니다.

* **YouTube**
* **Twitch**
* **CHZZK**

각 플랫폼의 플레이어 컨트롤 영역에 녹화, 스크린샷, 움짤 버튼이 추가됩니다.

---

## 📥 설치

### 1. Tampermonkey 설치

먼저 브라우저에 **Tampermonkey**를 설치합니다.

### 2. UserScript 설치

GitHub의 `youtube-gif-recorder.user.js` 파일에서 **Raw** 버튼을 클릭하면 Tampermonkey에서 설치할 수 있습니다.

설치가 완료되면 YouTube, Twitch 또는 CHZZK의 플레이어에서 기능을 사용할 수 있습니다.

---

## 🎮 사용 방법

플레이어 컨트롤바에 다음 기능 버튼이 추가됩니다.

### 🎥 녹화

현재 재생 중인 영상을 녹화합니다.

녹화 버튼을 다시 누르면 녹화를 종료하고 파일을 저장합니다.

브라우저에서 지원하는 형식에 따라 **MP4 또는 WebM**으로 저장됩니다.

### 📸 스크린샷

현재 영상의 프레임을 캡처하여 이미지 파일로 저장합니다.

### 🎞️ 움짤

현재 영상을 움짤로 녹화합니다.

녹화가 끝나면 원하는 구간과 GIF/WebP 옵션을 설정하여 최종 파일을 생성할 수 있습니다.

---

## ⌨️ 기본 단축키

| 기능        | 기본 단축키 |
| --------- | ------ |
| 🎥 녹화     | `F9`   |
| 📸 스크린샷   | `F10`  |
| 🎞️ 움짤 녹화 | `F8`   |

단축키는 설정 메뉴에서 원하는 키로 변경할 수 있습니다.

입력창이나 텍스트 편집 영역에서는 단축키가 작동하지 않도록 되어 있어 일반적인 입력을 방해하지 않습니다.

---

## ⚙️ 움짤 설정

움짤 제작 시 다음 항목을 설정할 수 있습니다.

### FPS

움짤의 프레임 수를 설정합니다.

기본 제공 프리셋:

`10 / 15 / 20 / 25 / 30 / 40 / 60 FPS`

### 가로 크기

움짤의 가로 해상도를 설정합니다.

기본 제공 프리셋:

`640 / 720 / 960 / 1280 / 1440 / 1600 / 1920 px`

원본 크기 또는 직접 입력도 사용할 수 있습니다.

### 화질

움짤의 화질을 설정합니다.

GIF/WebP의 일반적인 인코딩에서 화질 설정이 적용됩니다.

### 저장 형식

* GIF
* WebP

중에서 선택할 수 있습니다.

---

## 🖼️ GIF

GIF는 두 가지 제작 방식을 제공합니다.

### 일반 GIF

`gif.js`를 사용하여 GIF를 생성합니다.

### 고화질 GIF

`gifski-wasm`을 사용하여 고품질 GIF를 생성합니다.

고화질 모드는 일반 GIF보다 인코딩 시간이 오래 걸릴 수 있습니다.

---

## 🖼️ WebP

WebP 애니메이션 제작을 지원합니다.

### 손실 압축

화질 설정을 적용하여 파일 크기와 화질을 조절할 수 있습니다.

### 무손실 압축

무손실 방식으로 WebP 애니메이션을 생성합니다.

무손실 모드에서는 일반적인 화질 설정이 적용되지 않습니다.

---

## ✂️ 움짤 구간 지정

움짤 제작 시 **시작 시간과 종료 시간**을 직접 지정할 수 있습니다.

예:

`10초 → 15초`

처럼 원하는 구간만 선택하여 GIF 또는 WebP로 제작할 수 있습니다.

긴 영상을 전부 변환하지 않고 필요한 부분만 움짤로 만들 수 있어 메모리 사용량과 변환 시간을 줄이는 데 도움이 됩니다.

---

## 🤖 자동 생성

**자동 생성** 옵션을 활성화하면 움짤 녹화가 끝난 후 별도의 편집 과정 없이 저장된 설정값을 사용하여 바로 변환 및 저장합니다.

즉,

**움짤 녹화 → 자동 변환 → 자동 저장**

방식으로 사용할 수 있습니다.

자동 생성 기능을 사용하지 않으면 녹화가 끝난 후 설정창에서 원하는 구간과 옵션을 변경할 수 있습니다.

---

## 🎥 영상 녹화 비트레이트

일반 영상 녹화에는 별도의 **비트레이트 설정**을 사용할 수 있습니다.

기본 제공 옵션:

`1 / 2 / 3 / 4 / 8 / 12 / 20 Mbps`

직접 Mbps 값을 입력할 수도 있으며, **자동** 설정을 사용하면 영상 해상도에 따라 적절한 비트레이트를 자동으로 선택합니다.

> ※ 비트레이트 설정은 일반 영상 녹화에 적용되며 GIF/WebP 움짤 제작에는 적용되지 않습니다.

---

## 📁 자동 파일명

저장되는 파일은 영상 또는 방송 제목을 기반으로 자동으로 이름이 지정됩니다.

예:

```text
영상 제목_녹화_2026-08-31_14-05-23-123.mp4
영상 제목_스크린샷_2026-08-31_14-06-10-456.png
영상 제목_움짤_2026-08-31_14-07-32-789.gif
```

날짜와 시간뿐만 아니라 밀리초까지 포함하여 같은 영상에서 여러 번 저장해도 파일명이 겹칠 가능성을 줄였습니다.

파일명으로 사용할 수 없는 문자는 자동으로 처리됩니다.

* GIF 일반 / 고화질
* 자동 생성
* 녹화 비트레이트
* 녹화 단축키
* 스크린샷 단축키
* 움짤 단축키

## 🧠 메모리 및 성능

GIF/WebP 변환은 영상의 길이, FPS, 해상도에 따라 많은 메모리를 사용할 수 있습니다.

특히 다음 조건을 동시에 사용할 경우 메모리 사용량이 크게 증가할 수 있습니다.

* 높은 해상도
* 높은 FPS
* 긴 움짤 구간

WebP는 변환 과정에서 여러 프레임을 메모리에 보관하기 때문에 설정이 너무 높은 경우 예상 메모리 사용량을 표시하고 경고합니다.

변환에 실패하는 경우 다음 설정을 낮춰 다시 시도하세요.

* FPS
* 가로 크기
* 움짤 구간

## ⚠️ 주의사항

### 브라우저 호환성

영상 녹화는 브라우저의 `MediaRecorder` 및 영상 스트림 기능을 사용합니다.

브라우저에 따라 지원되는 녹화 형식이 다를 수 있습니다.

### 변환 시간

GIF/WebP 변환에는 영상 길이와 설정에 따라 시간이 걸릴 수 있습니다.

특히 고화질 GIF(gifski)는 일반 GIF보다 인코딩 시간이 오래 걸릴 수 있습니다.

### 사이트 변경

YouTube, Twitch, CHZZK의 플레이어 구조가 변경될 경우 버튼이 정상적으로 표시되지 않거나 일부 기능이 작동하지 않을 수 있습니다.

### 외부 라이브러리

움짤 변환을 위해 외부 CDN에서 다음 라이브러리를 불러옵니다.

* `gif.js`
* `gifski-wasm`
* `wasm-webp`

인터넷 연결이나 CDN 상태에 따라 움짤 변환 기능이 정상적으로 작동하지 않을 수 있습니다.
